## 轨道 A · 两个构建入口产出同名/近名可执行文件（P0，认错二进制）

### A-1 仓库根 `_build.bat` 构建的是 GUI，不是 CLI
- **复现**（当前 HEAD）：
  ```bash
  cd /d/_Progs/02Business/AsWish && cmd //c "_build.bat"   # 产出 bin/AsWish.exe
  head -8 AsWish.dpr          # program AsWish;  uses Vcl.Forms → GUI
  head -8 cli/AsWish.CLI.dpr  # program AsWish.CLI;  {$APPTYPE CONSOLE}
  ```
- **症状**：GUI 可执行文件接受任意命令行参数，**不校验、不报 unknown command**，
  在无控制台输出的情况下静默等待。表现与"进程挂死"完全一致。
- **为什么是 P0**：任何按文件名/按仓库根习惯找 CLI 的人都会拿到 GUI，
  而且**没有任何信号提示拿错了**。本次因此白烧约 40 分钟并差点上报假缺陷。
- **方案（三选一，推荐 1）**：
  1. 根 `_build.bat` 改为**同时构建两者**并打印醒目的产物对照表
     （`bin/AsWish.exe = GUI` / `cli/bin/AsWish.CLI.exe = CLI`）；
  2. GUI 入口对无法识别的命令行参数**拒绝启动**并打印用法（fail-closed）；
  3. 把 GUI 产物改名 `AsWish.GUI.exe`，从命名上消除歧义。
  至少做 2——它是唯一能让"认错"当场暴露的一条。
- **验收**：`_build.bat` 后，`bin/AsWish.exe foo bar` 必须非零退出并打印用法；
  构建日志末尾出现两个产物的明确标注。

### A-2 CLI 真实参数语法与 GUI 不同，且用错时不报错
- **复现**：
  ```bash
  ./cli/bin/AsWish.CLI.exe validate --project /tmp/x   # 把 "--project" 当 project-dir
  # 输出：[validate] skip (missing): trees/function-tree.yaml  ×4
  #       [validate] OK                     ← 退出码 0，"验证通过"
  ```
- **影响**：参数写错 → 目录解析错 → 四个树全 skip → **报 OK**。
  这是"静默成功"型缺陷，比崩溃更贵。
- **方案**：project-dir 参数若以 `-` 开头或不存在 `.AsWish` 且命令需要 spec 状态，
  必须报错退出；`validate` 在四个树全部 skip 时不得输出 `OK`。
- **验收**：上述命令退出码非 0 且错误信息指出"project-dir 解析为 --project"。

## 轨道 B · 两处静默失败的环境坑（P1，白烧时间）

### B-1 本机 `python3` 是 Microsoft Store 占位程序，失败时零输出
- **复现**：
  ```bash
  which python3    # /c/Users/.../WindowsApps/python3
  python3 -c "print('hello')"   # 无任何输出，退出码 49
  python --version              # 正常
  ```
- **影响**：`python3` 脚本**静默不执行**（连报错都没有）。本次写探针注入脚本时
  连续三次"执行成功但文件没变"，一度被误判为 AsWish 产品缺陷。
- **方案**：在仓库 `AGENTS.md` / `CLAUDE.md` 的环境说明里固定写死
  **本机用 `python`，不要用 `python3`**；`_repro/` 下的辅助脚本统一 shebang
  或调用 `python`。
- **验收**：新会话不需要试错就能选对解释器。

### B-2 把本机 Windows 可执行文件输出管到 `tail` 会死锁
- **复现**：
  ```bash
  ./AsWish.exe scan --project /tmp/x 2>&1 | tail -12
  # tail 要读完全部才输出，管道缓冲 64KB 写满后进程永久阻塞
  # 实测 scan 正常 7.7s 完成，挂住 10+ 分钟不动，CPU 仅 5.9s
  ```
- **影响**：与 A-1 叠加后看起来就像"产品挂死"。本次两个命令因此各挂数分钟。
- **方案**：本机运行本仓可执行文件**一律 `> file 2>&1` 再读文件**；
  写入 `AGENTS.md` 的"本机运行约定"一节。
- **验收**：工作流示例里不再出现 `| tail` 直连本机 exe 的写法。
