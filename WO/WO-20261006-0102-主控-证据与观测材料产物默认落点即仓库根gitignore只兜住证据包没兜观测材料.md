## 〇、一句话

两个生成器的**默认输出路径都是仓库根**。

- `generate_evidence.py` 写 `spw-evidence-<head>.json` → `.gitignore:42` **有兜住**；
- `build_obs_material.py` 写 `obs_material.json` → `.gitignore` **没有兜住**。

于是每次不带 `--output` 跑观测材料，仓库根就多一个**未忽略的游离文件**。
本轮实测：上一轮审计留下 16355B 的 `obs_material.json`，
本次执行 WO-0098 时又发现 `dogfood_gui/obs_material_7692003.json`
（那份在 ignore 目录里，但同样是无主产物）。

## 一、缺陷本体

### 1.1 默认落点是仓库根

```
tools/spw-evidence/build_obs_material.py:171-172
    if output_path is None:
        output_path = ROOT / "obs_material.json"
```

```
tools/spw-evidence/generate_evidence.py:425-426
    if output_dir is None:
        output_dir = ROOT
```

### 1.2 ignore 规则只覆盖了其中一类文件名

```
.gitignore:42   spw-evidence-*.json     ← 兜住证据包
.gitignore       obs_material*          ← 不存在
```

**两份产物性质完全相同**（都是派生证据，都该可重新生成），待遇却不同。

### 1.3 后果不是危险，是每次都脏

本轮实测两处 stray，都靠我在收尾时手工 `mv` 出仓库才清掉。
而 WO-0098 阶段 3 的判据是"`git status --porcelain` = 0（除本工单文件外）"——
**未忽略的 stray 会让验收条目 8 假阳**，把它算成"工作树不干净"，
或者更糟：忙起来忘了清，stray 被 `git add -A` 扫进提交。

## 二、执行阶段

### 阶段 1：默认落点改到专用于一次性的目录（必做）

两个生成器的默认输出改为**仓库根下一个明确的一次性目录**
（建议 `_repro/`，`.gitignore` 已 ignore 且语义正好是"内部复现目录"）：

- `build_obs_material.py`：`--output` 默认 `_repro/obs_material.json`；
- `generate_evidence.py`：`output_dir` 默认 `_repro/`；
- `--output` 显式传值的行为**完全不变**（外部调用方不受影响）。

### 阶段 2：ignore 规则补齐同类产物（必做）

`.gitignore` 在 `spw-evidence-*.json` 旁补 `obs_material*.json`，
并注释说明这是阶段 1 之外的**第二道防线**——将来再加同类产物时，
一眼能看到该往这个家族里加，而不是各自裸奔。

### 阶段 3：清掉现存 stray（必做）

`_repro/` 下目前已由主控暂存：

- `stray_obs_material.json.wo0097`（原仓库根 16355B 那份）
- `stray_obs_material_7692003.json.wo0097`（原 `dogfood_gui/` 那份）
- `_cf_marker_probe.txt.wo0098`（WO-0098 反证探针）
- `ledger_backup_wo0098.json` / `manifest_backup_wo0098.json` /
  `ledger_moved_away.json` / `ledger_old_gitignore_copy.json`

这些该删的删，该留的留。**注意**：`_repro/` 在 `.gitignore` 里，
`git status` 看不见它们——所以**必须显式清点，不能靠 `git status` 判断干净**。

## 四、禁条

1. **不得**把默认落点改成任何"看起来方便"的非 ignore 目录
   （如仓库根的 `out/`、当前工作目录）——那只是把污染换个位置。
2. **不得**用"加一条 ignore 规则"代替"改默认落点"——
   ignore 只让 `git status` 闭嘴，文件照样每个跑一次就往磁盘写一份，
   磁盘卫生问题没解决。

   靠的就是阶段 3 这种显式清点，不能又变成一个没人看的角落。
