## (d) Silent downgrade / fake-green risk

**HIGH — Single-harness self-report; no external observation field.**

- Evidence: `"_note": "... deliberately contains NO fields describing external-observation or certification outcomes of the audit run ..."`
- Evidence: every gate's verdict/exit_code/output_excerpt comes from the same subject SHA, same run, same harness. Example: `"subject_sha256": "ce2ef0e714f6cfd1edeb3cffc6a2146832275c16c7c2bbd051694c72be5d7177"` appears identically across all 12 gates, and there is no cross-run or independent-observer corroboration.

Why this matters (downgrade / fake-green vectors plausible from this pack alone):
1. **Fake-green by self-consistency.** `[CLAIM_ASSERTED] <name> | ... PASS` lines are emitted by the same gates whose PASS is being tested; a gate that asserts trivially without executing its counterfactual would still produce these exact bytes. No test-count / assertion-count / mutation outcome is provided for the H3 `counterfactual_*` claims beyond the marker string.
2. **Silent downgrade — zero-everything is indistinguishable from "not exercised."** H4 reports `0 hits (0 waived)` for all three patterns and `0` waivers; that is consistent with a clean tree *or* with patterns that never matched because the scanner scope is wrong. `"Scanned 89 Pascal source files (.pas/.dpr/.inc) across repository"` is the only scope evidence; there is no negative-control (a planted violation) shown.
3. **Boundary gate marker set not shown** (see (c)) — cannot distinguish "clean export" from "clean because we didn't check the right markers."
4. **Vendored drift gate is partly environmental.** `"[G.vendored-upstream-drift] 上游定位: D:\\_Progs\\02Business\\DeepBase"` — the check is anchored to a machine-local upstream path, and the `H4.HARDCODED_ABS_PATH` pattern is literally `"D:\\\\_Progs"`. The same absolute path family punished by H4 is used as the upstream anchor for G-drift. If the upstream directory is absent, PASS on "登记值一致" is compatible with a silently degraded comparison. Not proven, but a clean fake-green vector consistent with the material.
   - Evidence: `"pattern": "D:\\\\_Progs"` (H4) vs `"上游定位: D:\\_Progs\\02Business\\DeepBase"` (G.vendored-upstream-drift).

**Finding — HIGH** (area: silent downgrade / fake-green)
Description: All PASS verdicts are produced and asserted by a single self-referential harness with no external observation, no negative controls, and no marker/scope enumeration, so PASS is not independently distinguishable from "check not exercised."
