### 2. Evidence 读写与实现证据收集服务 ([`src/services/AsWish.Services.SpecStore.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.SpecStore.pas) & [`src/services/AsWish.Services.EvidenceCollector.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.EvidenceCollector.pas))
- **`ReadEvidenceFile`**：完整解析并回读 `source-evidence.yaml` 与 `implementation-evidence.yaml`。
- **`TAsWishEvidenceCollectorService`**：
  - 严格践行 `Agent Claim ≠ Evidence`。
  - 三件套收集：`SourceFileHash`（SHA256）、结构抽样（`Lines` / `Excerpt`）、节点关联回填（`ReferencedBy`）。
  - 缺失文件/无效基线严格 fail-closed。
  - 自动落盘至 `.AsWish/evidence/implementation-evidence.yaml`。

### 3. P2 单树哈希修复与差异引擎 ([`src/services/AsWish.Services.Snapshot.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.Snapshot.pas) & [`src/services/AsWish.Services.Difference.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.Difference.pas))
- **P2 修复**：`CreateBaseline` 与 `VerifyBaseline` 修复为**单树粒度**哈希计算（仅根据触发基线冻结的 `tree_type` 计算 `content_hash` 与 `relation_hash`，彻底消除四树强行合并）。
- **`TAsWishDifferenceService`**：
  - 差异计算判定：
    - `dkMissing`：基线存在，活体树/实现证据缺失。
    - `dkExtra`：活体存在，基线未定义。
    - `dkChanged`：ContentHash 或 RelationHash 改变（细分 `daContent`, `daRelation`, `daBoth`）。
  - 自动写出/回读 `.AsWish/difference.yaml`。

### 4. 裁决决策与双出口支持 ([`src/services/AsWish.Services.Decisions.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.Decisions.pas))
- **`RecordDifferenceDecision`**：
  - `acceptable` ➔ `dtAcceptDifference` / `dsAccepted`
  - `unacceptable` ➔ `dtReject` / `dsRejected`
  - `unresolved` ➔ `dtClarify` / `dsProposed`
  - `TargetNodes` 自动收集差异项节点列表。
- **Revision 出口**：记录 `dtReject`，通过 B' 意图入口重新进入意图链。
- **Evolution 出口**：记录 `dtAcceptDifference`，直接从当前实现现实冻结新基线（`ParentBaselineId` 指向父基线）。
- **零新增实体结构**：完全复用 `TSpecDecision` 与 `TAsWishBaseline`，零架构分叉。

### 5. B' GUI 新意图入口 ([`src/services/AsWish.Services.Render.pas`](file:///D:/_Progs/02Business/AsWish/src/services/AsWish.Services.Render.pas))
- 在 `RenderIndex` 与 `RenderNodeDetail` 中嵌入 B' 自然语言新意图提交表单及 JS Bridge。
- 支持在无 ChangeSet 处于激活状态时，直接从空白/任意节点发起下一轮迭代闭环。
- 完整保留 UTF-8 BOM，彻底解决 Windows Delphi ANSI 乱码风险。

### 6. CLI 完整子命令扩展 ([`cli/AsWish.CLI.dpr`](file:///D:/_Progs/02Business/AsWish/cli/AsWish.CLI.dpr))
