## 任务（单事项）

**已核实的第一个事实——忽略清单没盖住这些目录**：

`.gitignore` 里有 `.claude/`、`dogfood_*/`、`scratch_*/`、`boundary.json` 等，
但**没有** `.AsWish/`、`.ai-workbench/`、`_repro/`、`_audit_out.txt`、
`_audit_err.txt`、`err_file`、`out_file`。

**已核实的第二个事实——内部治理材料确实躺在未忽略区里**：

`.AsWish/` 下有 58 个文件，其中含内部治理标记（`主控`/`开发AI`/`BetterCiv`）
的实 grep 命中 **12 个**：

```text
.AsWish/docs-summary.yaml
.AsWish/evidence/implementation-evidence.yaml
.AsWish/evidence/source-evidence.yaml
.AsWish/html/evidence.html
.AsWish/html/function-tree.html
.AsWish/html/problems.html
.AsWish/html/scan-report.html
.AsWish/scan-report.yaml
.AsWish/snapshots/.../trees/function-tree.yaml   （两处）
.AsWish/snapshots/function-tree.bak.yaml
.AsWish/trees/function-tree.yaml
```

**已核实的第三个事实——假绿灯的坑在哪**：

`.AsWish/` 里自带的 `.gitignore` 会让人误判为安全：

```text
$ git check-ignore -v .AsWish/
.AsWish/.gitignore:8:	.AsWish/        ← 看起来"已忽略"
```

但那份嵌套 `.gitignore` 盖住的是 `snapshots/`、`html/` 等重目录，
**`commons/lesson-000*.yaml`、`decisions/`、`evidence/`、`docs-summary.yaml`
这些全没盖住**。目录级 check-ignore 给了个安心的假象，
`git status --untracked-files=all -- .AsWish/` 一跑就是 **24 个未忽略文件**。

**决定性取证——`git add -A --dry-run`**：

```text
$ git add -A --dry-run | grep -cE "\.AsWish|\.ai-workbench"
50
```

50 个文件会被扫进索引，其中就包含上面那 12 个带内部标记的。
也就是说：**现在如果有人执行封版提交时图省事打一个 `git add -A`，
内部治理材料直接进公开仓库。** 这不是假设，是 dry-run 已经演出来的后果。
