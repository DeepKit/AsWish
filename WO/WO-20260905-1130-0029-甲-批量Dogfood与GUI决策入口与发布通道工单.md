## 二、P1 · 批量/多项目 Dogfood（CLI headless 全链）

### 范围
1. 编写批量 Dogfood 跑批脚本（PowerShell，入 `09_工程脚本/` 或仓库 `scripts/`，遵循仓库既有脚本位置约定），一条命令跑完 N 个项目的完整链路；
2. 准备 **≥3 个异构测试项目**（领域不同、规模不同，如：小工具项目 / 中型多模块项目 / 含边缘结构的实际仓库切片），每个项目独立 `.AsWish` 现场；
3. 每个项目跑全链：`init → scan → intent → ingest → changeset 提交与 accept → baseline → difference → judge（至少一个 unacceptable 拒绝 + 一个 accept）→ evidence collect → evolve`；
4. 验证各项目决策文件 ID 单调唯一、基线 lineage 完整（含 `parent_baseline_id`）、双闸门 PASS。

### 验收硬标准
- 3 项目 × 全链，0 手工修数据，脚本可重复执行（重跑幂等或可再生新现场）；
- 每项目现场目录保留，跑批原始输出（含 Exit code）存档；
- 跑批中发现的缺陷修复后须回归全量测试。
