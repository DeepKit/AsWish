## 使用纪律

1. **只读**：归档内容不再维护，不随现行文档更新。
2. **不引用**：现行文档不得把归档文件当作权威来源；需要时把内容整合进现行文档后再引用。
3. **失效口径保留**：历史文档中的失效口径（如"三棵树"）作为历史事实保留，不作为实现依据。
4. **新归档**：凡是被现行文档取代的文件，一律移入此处并在文件名/目录上标注来源与时间。
